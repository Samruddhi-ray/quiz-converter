How to write your questions

In text or Word: number each question, letter the options, and mark the right answer with * (in Word, you can make the right answer bold instead).

1. Which organ pumps blood? [2 pts]
a) Lungs
*b) Heart
c) Liver

2. Which are prime numbers?
*a) 2
*b) 3
c) 4

3. The Earth orbits the Sun.
*a) True
b) False

4. What is the chemical symbol for water?
Answer: H2O | h2o

5. Explain photosynthesis in your own words.
You writeYou get
Options with one *Multiple choice
Options with two or more *Multiple answers
Options True / FalseTrue/False
Answer: … and no options (separate accepted answers with |)Short answer (fill in the blank)
No options and no answerEssay
[2 pts] at the end of the questionPoints (default is 1)
Answer: B under the optionsMarks option B as correct (instead of *)

In Excel or CSV: use the template. Columns: Type (MC, MA, TF, SA, Essay), Question, Points, Correct (for example B, A,C, True, or Paris|paris), then Option A to Option F.

3Check and download

Add some questions to see a preview.

    4Import into Canvas

    1. In your course, open Settings, then Import Course Content.
    2. For Content Type, choose QTI .zip file, and choose the file you downloaded.
    3. If your course uses New Quizzes, tick Import existing quizzes as New Quizzes (if you see it).
    4. Click Import. Your quiz appears under Quizzes, unpublished, so you can check it before students see it.

    Always preview the quiz in Canvas before publishing.
