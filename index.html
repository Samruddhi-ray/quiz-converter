    Questions

    How do I format my questions?

    Number each question, letter the options, and put * before the right answer. In Word, you can make the right answer bold instead.

    1. Which organ pumps blood? [2 pts]
a) Lungs
*b) Heart
c) Liver

2. Which are prime numbers?
*a) 2
*b) 3
c) 4

3. The Earth orbits the Sun.
*a) True
b) False

4. What is the chemical symbol for water?
Answer: H2O | h2o

5. Explain photosynthesis in your own words.
    You writeYou get
    Options with one *Multiple choice
    Options with two or more *Multiple answers
    Options True / FalseTrue/False
    Answer: … and no options (separate answers with |)Short answer
    No options and no answerEssay
    [2 pts] at the end of the questionPoints (default 1)
    Answer: B under the optionsMarks B as correct

    Excel or CSV: download the template. Columns: Type (MC, MA, TF, SA, Essay), Question, Points, Correct (B, A,C, True or Paris|paris), then Option A to Option F.

    Is it really private?

    Yes. Your file is read by your own browser, and your questions never leave your computer. The page has a built-in security rule that blocks it from sending data over the internet. The only thing counted is an anonymous page visit (no cookies, no personal data), so we know whether teachers find the tool useful. The code is open source, so anyone can check it.

    Does it work with New Quizzes?

    Yes. During import, tick Import existing quizzes as New Quizzes if your course shows that option. Otherwise the quiz arrives as a Classic Quiz.

    What can't it do yet?
    • Images, equations and tables inside questions: add them in Canvas after importing.
    • Old .doc and .xls files: save them as .docx or .xlsx first.
    • Answer keys listed separately at the end of a document: put Answer: B under each question instead.
